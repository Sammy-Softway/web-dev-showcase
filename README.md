## Core Engineering Focus
Across every project in this repository, I focus on applying real-world software development habits:
- **Independent Problem Solving:** Breaking down a blank-slate prompt into smaller milestones before writing code.
- **Clean & Maintainable Code:** Applying principles like **DRY (Don't Repeat Yourself)** and Object-Oriented Programming (OOP).
- **Documenting the Journey:** Each project folder includes its own `README.md` with setup instructions alongside honest reflections on what went well, what was challenging, and what I learned.

## How to Explore & Run Any Project
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/Sammy-Softway/web-dev-showcase.git
   ```
2. Navigate into the specific project folder you want to test (e.g., `tic-tac-toe-game`):
   ```bash
   cd tic-tac-toe-game
   ```
3. Follow the individual `README.md` inside that folder for dependencies and run instructions.
