# Tic-Tac-Toe (Python)

A command-line Tic-Tac-Toe game built with Python. Two players take turns marking spaces on a 3×3 grid until one player aligns three marks or the game ends in a draw.

## Features
- Interactive 3×3 game board rendered in the terminal
- Automatic win and tie detection
- Input validation to prevent overwriting taken spaces

## Prerequisites
- Python 3.x installed on your machine

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/Sammy-Softway/web-dev-showcase.git
   ```
2. Navigate to the project folder:
   ```bash
   cd tic-tac-toe-game
   ```
3. Run the game:
   ```bash
   python main.py
   ```

## How to Play
1. Player 1 is **X** and Player 2 is **O**.
2. On your turn, enter the position number corresponding to an empty spot on the board.
3. The first player to get three of their marks in a row (horizontally, vertically, or diagonally) wins.

## Example Gameplay
```text
 X | O | X 
---+---+---
 4 | X | O 
---+---+---
 7 | 8 | 9 
```
